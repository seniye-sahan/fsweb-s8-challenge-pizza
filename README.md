# Pizza Ordering Application

A responsive pizza ordering application developed with React as part of my Full Stack Development training at Workintech.

## Technologies

- React
- JavaScript
- Tailwind CSS
- Axios
- Cypress
- Vite

## Features

- Responsive pizza ordering interface
- Dynamic topping selection
- Minimum and maximum topping validation
- Dynamic price calculation
- Form validation
- Order submission using Axios
- State management with React Hooks
- Cypress tests for user interactions and form behavior
- Mobile-first responsive design

## Installation

Clone the repository:

git clone https://github.com/seniye-sahan/fsweb-s8-challenge-pizza.git

Install dependencies:

npm install

Run the project:

npm run dev

## Testing

Run Cypress tests:

npx cypress open
